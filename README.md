# OmniZip releases

Free archive utility from [OmniArk](https://omniark.co/tools/omnizip).

This repository contains downloadable applications and validation workflows, not the application source. Free download does not imply an open-source license for OmniZip. Third-party licenses and the 7-Zip source are included in each application bundle.

Mac builds are beta software without Apple Developer ID signing or notarization. macOS may block the first launch. Only allow an app if you trust its origin; never disable system-wide security protections. See [Apple's instructions](https://support.apple.com/en-us/102445). Version 0.3.1 registers ZIP, 7Z, RAR, and split 001 archives as Finder “Open With” candidates without replacing the user's existing default application.

Automated macOS checks cover native engine round trips and application startup. They do not guarantee every archive format, device, or interactive workflow.
